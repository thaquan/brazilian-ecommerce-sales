# GitHub release notes

The public repository contains sanitized source, templates, reports, documentation, and selected evidence. Raw data, PBIX files, cache folders, credentials, recovery keys, and account screenshots are excluded.

The project code is released under MIT. Dataset and third-party asset terms remain separate; see `docs/sources.md`.

For another environment, clone the repository, remap all Fabric and SQL connections, run the runbook, and record fresh validation evidence. Do not treat the sample IDs in the public files as live configuration.
