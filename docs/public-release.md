# Public release notes

This repository is a sanitized portfolio release. Original tenant IDs, workspace IDs, item GUIDs, account names, machine names, hostnames, and RLS identities were replaced with sample or synthetic values. ZIP and PQT templates were rewritten as sanitized copies.

The public release does not contain credentials, recovery keys, raw source data, PBIX cache files, or Fabric account screenshots. The five report screenshots are Desktop report views without account chrome.

Before running it, replace workspace, Lakehouse, Warehouse, notebook, pipeline, connection, OneLake endpoint, SQL Server, gateway, and RLS values. The sample IDs are not valid deployment targets. The public release has not been deployed to a clean tenant.

The original private evidence bundle is retained locally by the project owner and is not part of the public Git history.
